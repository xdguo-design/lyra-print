# 打印模板 AI 辅助设计

**状态**：已根据当前需求形成设计草案
**范围**：纸质发票照片矫正、模板拖拽排版、表格设计和 AI 自动定位

## 1. 目标

让设计人员可以拍摄或上传一张纸质发票或表单照片，在平台内设置实际纸张尺寸。平台自动识别照片四角，完成裁剪、透视校正、旋转和拉伸适配，再以矫正后的照片为参照拖拽制作模板；必要时调用外部 AI 识别版式并生成候选组件，人工确认后保存为平台自己的可编辑模板配置。

核心原则：AI 是加速器，不是运行时依赖；模板保存后，预览和打印不需要 AI 在线。

## 2. 方案比较

### 方案 A：纯手工拖拽

优点：最可控、数据不外发、实现简单。

缺点：制作发票和复杂表格耗时，重复劳动多。

### 方案 B：AI 一键生成

优点：速度最快。

缺点：复杂表格、字体、合并单元格和固定票据容易识别错误；用户难以理解 AI 为什么这样布局。

### 方案 C：AI 识别 + 人工确认（推荐）

先由 AI 识别文本、表格、条码、边框和版式区域，再转换为可编辑组件。设计人员可以逐项确认和修正，最后保存模板。

选择原因：兼顾效率、可控性和模板质量；AI 失败时仍可回到纯手工模式。

## 3. 核心工作区

```text
左侧：组件库 / 图层树
中间：毫米级打印画布 / 矫正后的照片叠加层
右侧：组件属性 / 字段绑定 / 转换规则 / AI 识别结果
```

### 3.1 画布能力

- 设置纸张宽度、高度、方向和单位。
- 拍摄或上传纸质发票照片。
- 自动检测照片四边和四角。
- 自动裁剪、去背景、旋转和透视校正。
- 根据纸张实际宽高完成拉伸和尺寸适配。
- 支持四角手工校准、缩放、裁剪和透明度。
- 矫正照片背景锁定，避免误拖动。
- 标尺、网格、对齐线和吸附。
- 组件拖拽、缩放、复制、删除、锁定和图层排序。
- 原图、模板、叠加、差异高亮四种查看模式。

### 3.2 组件能力

- 文本、长文本、图片、线条、矩形。
- 表格、动态明细、页眉、页脚和页码。
- 条码、二维码、金额和日期。
- 条件显示、重复区域和跨页区域。

### 3.3 表格能力

- 行列增删。
- 单元格合并和拆分。
- 动态明细行。
- 多行表头。
- 跨页重复表头。
- 分组、小计、总计。
- 空数据隐藏和固定合计区域。

## 4. AI 识别流程

1. 用户拍摄或上传纸质发票照片。
2. 用户设置实际纸张大小和打印尺寸。
3. 平台自动检测四角、裁剪背景、透视校正并完成拉伸适配。
4. 用户确认或手工调整四个角点。
5. 平台显示矫正照片参照层。
6. 用户触发 AI 识别。
7. 外部 AI 返回识别候选：文本框、表格、条码、二维码、线条和版式区域。
8. 平台把候选结果转换为内部模板组件。
9. 右侧面板展示识别置信度和待确认项。
10. 用户确认、修改、删除或重新识别。
11. 使用样例数据生成预览。
12. 通过叠加或差异模式完成版式校验。
13. 保存模板配置、原始照片、矫正照片、校准点、尺寸、映射、转换规则和识别记录。

## 5. 外部 AI 边界

- 外部 AI 可配置，不要求首期私有化部署。
- AI 只负责版式识别、坐标定位和候选组件生成。
- AI 不负责金额计算、开票判断、收费判断或其他业务规则。
- AI 输出必须转换为平台自己的模板结构。
- 模板发布后，渲染、预览和打印不依赖 AI。
- 图片外发前应给出提示，并支持按策略脱敏或人工确认。
- 记录 AI 供应商、模型、任务状态、识别版本和人工修正记录。
- AI 服务只接收经过用户确认可以外发的照片或矫正图。

## 6. 保存模型

最终至少保存以下信息：

- 模板版本。
- 页面尺寸和打印尺寸。
- 原始发票照片、矫正照片及其校准信息。
- 组件布局。
- 数据字段映射。
- 通用转换规则。
- 表格结构和合并关系。
- AI 识别结果。
- 人工修正记录。

推荐以模板 JSON 作为可编辑主数据，数据库保存版本和审计信息。原始图片的保存位置和留存周期可配置。

## 7. 失败处理

| 场景 | 处理 |
|---|---|
| AI 服务超时 | 提示失败，保留图片和当前手工编辑状态 |
| 识别结果不准确 | 支持逐项修正、删除和重新识别 |
| 图片尺寸未知 | 要求用户设置纸张尺寸或通过校准点确认 |
| 照片四角识别失败 | 提示用户手工拖动四角，或直接进入手工模板设计 |
| 照片倾斜、反光或阴影严重 | 提示重新拍摄，也允许继续人工校正 |
| 照片被遮挡或纸张弯曲 | 标记低置信度区域，不自动覆盖用户配置 |
| 表格识别失败 | 允许手工创建表格和合并单元格 |
| 外部 AI 不可用 | 完全回退到手工模板设计 |
| 模板保存失败 | 保留本地草稿，提示重试 |

## 8. 验收标准

- [ ] 可拍摄或上传纸质发票照片并设置宽度、高度和方向。
- [ ] 可自动检测照片四角、裁剪、透视校正和拉伸适配。
- [ ] 四角识别失败时可以手工调整四个角点。
- [ ] 矫正照片可作为锁定背景叠加到设计画布。
- [ ] 用户可拖拽文本、表格、二维码和线条组件。
- [ ] 表格支持增删行列、合并单元格和动态明细。
- [ ] AI 可返回候选文本、表格和版式区域。
- [ ] AI 结果可编辑、可撤销、可重新识别。
- [ ] 原图和模板渲染结果可以叠加或差异对比。
- [ ] AI 服务不可用时仍可手工完成模板。
- [ ] 模板保存后可脱离 AI 服务预览和打印。
- [ ] 模板 JSON、版本、尺寸和识别结果均可追溯。
