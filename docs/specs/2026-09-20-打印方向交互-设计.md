# 打印平台交互原型设计

## 目标
把 `prototype-directions.html` 从静态方向展示页升级为可走通主要操作路径的本地交互原型。

## 交互范围
- 三个方向页可切换，并与左侧模块导航联动。
- 搜索框实时过滤模板、设备和任务列表。
- 模板工作台支持组件加入图层、图层选中、属性编辑、保存/预览状态。
- 发票照片上传后显示；校正、叠加和差异高亮切换视觉状态。
- 打印任务支持查看、重试、换机；设备支持在线/异常筛选；刷新更新时间。
- 通过详情弹层展示模板、设备、任务、数据源和接入文档信息。

## 技术约束
- 继续使用单个自包含 HTML 文件。
- 只使用原生 HTML/CSS/JavaScript，不接真实服务、不执行真实打印。
- 数据保存在内存，刷新后恢复示例数据。
- 保留现有视觉风格和响应式布局。

## 验收标准
- 点击左侧导航、方向切换、搜索、模板组件、上传、任务操作时，页面状态可见变化。
- 详情弹层可打开和关闭，键盘 Escape 可关闭。
- 页面无脚本报错，桌面和窄屏布局仍可访问。
